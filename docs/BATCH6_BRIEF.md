## 1. 模拟：6 小时陆战结算（`src/sim/systems/landCombatSystem.ts`）
- 严格按 §4.9 第 2–3 节：每个 Tick（6h）进行省级战斗状态机。
  - 槽位：单向进攻 4 前锋 + 2 支援；高山/沼泽 3+1；都市 5+2；每多一个不同相邻进攻方向，两边各 +2 前锋 +1 支援。
  - 预备队轮换（25% 概率替换组织度 <15% 的旅），重炮旅无前锋掩护单独接敌时防御减半。
  - 有效攻防乘算链：满编率、地形（§4.9 第 4 节的表）、渡河、要塞、堑壕（每天 +3%，上限 +24%）、攻势筹备（每天 +3%，上限 +24%，开打后每天 -2%）。本批没有的系数（补给、空军、夜战）固定为 1.0，并在拆解里显示“未启用”。
  - 招架（命中 0.10）与溢出暴击（0.30）；装甲 `Arm > Prc` 压制（受组织伤害 ×0.60，造成组织伤害 ×1.35）。
  - ΔOrg = 有效命中 ×1.35，ΔStrength = 有效命中 ×0.22；Strength 损失按 60% 计人力伤亡、40% 计装备损毁（接入现有人力/仓库，累计战损写入顶栏/F1 已有字段）。
- 全部用现有 FixedMath 定点数和 SeededRng，**同种子同输入必须逐位一致**。
- 数值常量集中放 `src/sim/data/combatDefines.ts`（或 `public/data/balance/combat_defines.json` 加 TS 镜像），方便以后调平衡。

## 2. 模拟：溃退、占领与合围歼灭
- 守方前锋组织度全部 ≤0 且没有预备队可补位时溃退：撤往相邻、本方控制、未交战的省（优先离首都近的），进攻方先头部队进占该省并改控制权（军事占领，双色斜纹，片元着色器在屏幕像素空间或固定世界比例计算，缩放无摩尔纹）。
- 合围：撤退时所有相邻陆地省都被敌控、也没有友方港口，则整建制覆灭，100% 损失；进攻方缴获其满编装备 15% 入库（缴获守恒要能测）。
- 每日扫描并标记“被围口袋”（与首都不连通的本方部队连通块），供渲染用。
- **进攻箭头真正驱动进攻**：集团军的进攻箭头命令现在要执行。沿箭头方向，前线部队对相邻敌省发起进攻；胜利后推进并继续朝目标省，直到抵达或被挡住。玩家 `manualOverride` 的旅照旧不被 AI 抢走。不做补给约束（Batch 07）。
- 本批需要一个测试用的战争状态：沿用或新增 URL 参数 `mockWar=GER_POL`（德波交战），以及 `tick=` 快进；不做完整宣战外交（那是后面批次）。

## 3. 渲染与 UI：本批的可读性打磨点（原创风格）
1. **战线**：沿交战双方**整条接触边界**连续绘制（不再只是一小段），更粗的双层墨线；锯齿一律朝向敌方；颜色跟随所属集团军色签（每个集团军一种低饱和矿物色）。不得抖动、断裂或在海岸处乱跳。
2. **手写体标注**：战线和箭头上沿曲线排一行手写体（LXGW 文楷子集），如「第 1 集团军 · 12 旅」；LOD 0 远景自动隐藏；彼此之间和与城市名之间不得重叠。
3. **进攻箭头**：起点吸附到战线上；目标省盖一层集团军色的铅笔斜线（hatch）。执行中流光加快，停止时变静止虚线（§2.5）。
4. **军牌**：
   - 敌我分明：己方、盟友、敌方的卡纸底色或边框明显不同（例如己方米白卡纸、敌方灰褐卡纸加朱红细边；颜色自己按 ART_BIBLE 定）。
   - 中景（LOD 1–2）把组织度/兵力双进度条加粗；低于 30% 变警示色。
   - 中景淡化或隐藏与玩家无关的中立国军牌（只保留玩家、盟友、交战方），解决 `counters_front_zoom` 的拥挤问题。
5. **集团军卡**：左下（不要挡住现有的指令胶囊和底部指令栏）放一排小卡：色签、集团军名、旅数、指挥官名；点击即选中该集团军并高亮对应战线。每个集团军最多一名将领、1–2 个特性（如“装甲先锋 +10%”），在 F6 里指派。**不做军官团**。将领用原创虚构名字或历史人名文本，不用任何照片或游戏头像，可用简单的原创剪影或首字母徽章。
6. **交战印章**：正在交战的省放一枚原创“交叉刺刀”小印章（SVG，自己画），按优势方着色并显示攻方优势值；点击打开右侧战地简报抽屉。
7. **包围口袋**：被围的部队块整体外圈一条虚线环加「被围」字样，**不要**额外画一堆箭头；全歼时弹出一次「合围歼灭 ×N 旅」战报徽章（不要长时间遮挡地图）。
8. **战地简报抽屉**（`src/ui/drawers/BattleReportDrawer.tsx`）：按 §6.3 第 2 节线框：战役名（地形·渡河）、持续时间、双方槽宽、前锋/支援槽矩阵（每旅组织|兵力）、预备队、选中旅的有效攻击乘数逐项拆解、当前优势评估、堑壕/筹备加成。宽度沿用右抽屉规格，不挡地图主体。
- 渲染模块建议：`src/render/CombatBubbleLayer.ts`（交战印章与气泡）、`src/render/PocketLayer.ts`（包围环），以及修改 `frontlineGeometry.ts` / `FrontlineArrowLayer.ts` / `UnitCounterLayer.ts` / `counterArt.ts`。

## 4. 测试（vitest，新增）
- 战斗确定性：同种子同输入跑 N 个 tick，状态哈希逐位一致；换种子则不同。
- 槽位：单向 4+2、三向夹击拓宽、高山/沼泽 3+1、都市 5+2。
- 重炮旅单独接敌防御减半；装甲压制开关（Arm>Prc vs Arm≤Prc）。
- 地形/渡河修正（高山、跨大河）。
- 溃退：守方组织度归零后撤往正确的相邻省，攻方进占并改控制权。
- 合围：无路可退时整建制覆灭，缴获 15% 装备，人力与装备守恒。
- 进攻箭头执行：设定箭头后若干 tick 内部队推进至少 1 省。
- 原有 32 项测试必须继续全绿。
