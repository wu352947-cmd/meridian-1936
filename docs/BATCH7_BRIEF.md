## 1. 模拟：补给网（`src/sim/systems/supplySystem.ts`）
- 严格按 §4.10：每日 00:00 全图多源 Dijkstra。
  - 补给源：本国首都 S=100；本土 VP≥15 的工业核心都市 S=85（数据里没有 VP 就用现有都市/工业区数据挑出，写进 `src/sim/data/supplySources1936.ts` 并注明规则）；友方港口 S=35+13×港口等级（本批没有海军，港口视为与本土连通，海区护航折减留到海军批次，代码留接口）。
  - 每跨一省的阻抗：BaseTerrainCost（平原/都市 6、森林/丘陵 10、荒漠/沼泽 15、高山 18）÷ 基建倍率（1–5 级：0.8/1.0/1.25/1.5/1.8，取所属行政区 infra）+ 占领惩罚（新占领不足 14 天 +8）− 卡车减免（集团军开启“摩托化补给”且仓库卡车充足时 −3，扣卡车消耗）。
  - 补给只在本国及盟友控制省传播；敌控省阻断。
  - 结果 S_p ∈ [0,100] 用定点整数，存 `Int16Array`/`Uint8Array`，通过现有快照协议传给主线程。
- 供养上限 Cap_p = max(1, ⌊S_p/15⌋)。
- **缺粮**（N > Cap_p 或 S_p < 30）：行军速度最多 −50%，组织度恢复停止，攻防按缺口线性 −10%～−50%。
- **断粮**（S_p = 0 满 48 小时 = 8 Tick）：每 Tick −4 组织度、−1.5% 装备，攻防固定 −60%。
- 性能：676 省全图重算 < 0.5ms（vitest 里测，宽松阈值以免 CI 抖动）。

## 2. 模拟：季节与天气（`src/sim/systems/weatherSystem.ts`）
- 按 §4.1：按气候带 + 月份确定性生效，不做逐省随机云雨。
  - 气候带：西欧温带、地中海/北非干旱、北欧亚寒带、东欧大陆性。按省坐标/所属国家划分，写成数据表（`src/sim/data/climateZones1936.ts`）。
  - 东欧泥泞季（4 月、10 月下半月）：行军 −40%，装甲/摩托化进攻 −35%。
  - 东欧与北欧严冬（12 月–2 月）：非山地旅进攻 −25%，缺补给损耗翻倍；芬兰、苏联固有抗寒抵消一半。
  - 18:00 夜间 Tick：陆战双方攻击 ×0.75。空军出动率 ×0.5 只留接口（空军批次再接）。
- 全部定点数、确定性。

## 4. 渲染与 UI（原创参谋图风格）
1. **M3 后勤补给地图模式**：省份按 S_p 着色，翠绿（80–100）→ 琥珀（40–79）→ 铁锈红（<40）→ 黑红斜纹（0 断粮）。同时提供色盲安全的蓝–灰–橙第二套色表（设置里或 URL 参数 `cb=1` 切换）。补给源标记：首都、核心都市、港口用原创小锚标/星标（自绘 SVG）。斜纹在屏幕像素空间算，缩放无摩尔纹。
2. **季节天气叠层**：严冬时地图四角浮现淡淡冰霜，泥泞季浮现泥渍（自己画或程序生成的纹理）；受影响的气候带有一层很淡的冷蓝或泥褐色调。整体要克制，不能让地图变脏、文字变难读。右上时钟旁显示当前季节小标签（如「东欧 · 严冬」）。
3. **兵牌**：缺粮时兵牌右上角亮一个原创红色油桶叹号小标；断粮时兵牌边框变黑红并闪一次。
4. **战地简报抽屉**：补给、季节、夜战显示真实乘数，并写出来源（例如「补给 S=24 · 缺粮 −32%」「东欧泥泞 · 装甲 −35%」「夜间 ×0.75」）。
5. **F5 后勤抽屉**（`src/ui/drawers/LogisticsDrawer.tsx`，替换 F5 占位）：本国补给概况（各集团军平均 S、缺粮/断粮旅数、卡车库存与“摩托化补给”开关）、补给源列表、当前季节天气及下一次变化日期。占领与抵抗部分**不做**（后面批次），只留一个标题占位「占领管理（后续开放）」。
