## 2. 训练部署队列（接 Batch 3/4）
- 训练一个旅：从可用人力扣除该模板人力；从 Batch 03 军需库存扣装备。装备不足时可开训但满编率按最短缺比例降低（或排队等待——二选一，写清规则与测试）。
- 训练时长：步兵/守备 **35 天**，摩托化、山地、炮兵按合理中间值（如 45 天），装甲 **60 天**；兵役法“广泛征兵 +10% 训练耗时”等 Batch 04 修正要生效。
- 训练完成后部署到玩家选定的本国省份（默认首都或指定省），成为在编旅。
- **替换 Batch 04 的占位**：顶栏/人力抽屉里的“在编人数”改为真实在编旅人力之和（不再用 开局旅数×10000）；“累计战损”在本批仍为 0（战斗在 Batch 06）。
- 开局部队：各国按现有 `brigades` 数量生成起始旅（类型配比合理，如德国含少量 ARM/MOT，法国多 INF+ART），驻扎在历史大致防区（边境/首都/要塞区），不要全堆首都。

## 3. 集团军、行军与命令（模拟层）
- 单层“集团军”（上限 16 旅），可新建/解散/分配旅。
- 跨省行军：陆地 A* 最短耗时，按地形速度倍率（平原 1.0、森林/丘陵 0.75、高山 0.45、沼泽 0.50、都市 0.90、荒漠 0.85）与旅速度计算；**未处于交战状态的他国领土禁止进入**（可通行协定留后续批次）。
- 战线：集团军绑定一段与目标国接壤的边境，基于拓扑共享边界弧段提取连续折线；把集团军的旅**均摊**到战线沿线的己方边境省，不留空洞。
- 进攻箭头：玩家可在地图上从战线拖拽绘制（或点选起止省生成）贝塞尔进攻箭头，存为命令（目标省序列）；本批不结算交战，只显示与存储。
- `manualOverride`：玩家手动指挥的旅打上锁标，集团军自动分派在其抵达目的地前不得覆盖。
- `src/sim/` 不引用 DOM/PIXI；使用定点/确定性逻辑。建议模块：`src/sim/systems/armySystem.ts`、`src/sim/systems/armyOrderSystem.ts`、`src/sim/systems/pathfinding.ts`。

## 4. 地图渲染（视觉重点）
- `src/render/UnitCounterLayer.ts`：**原创改良北约军牌**（不要照搬 HOI4 计数器外观）：约 44×28px 圆角硬卡纸，1px 深墨边与微投影；左侧国家主题色 + 小中性旗徽；中央白底黑线几何军标：INF 对角交叉、MTN 交叉+山峰、MOT 交叉+轮圈、ARM 横椭圆履带环、ART 实心圆点、GAR 单斜杠/盾；右侧等宽堆叠旅数；底部两条 3px 状态条：上翠绿 Org、下琥珀 Strength。纯 Pixi Graphics/SVG 生成，缩放锐利。

- `src/render/FrontlineArrowLayer.ts`：参谋风格齿状/锯齿战线（沿拓扑弧段，**连续、平滑、无抖动、无断裂**）；进攻箭头为贝塞尔曲线，流动条纹、箭头头部干净，无折角撕裂。颜色与纸质地图气质一致，不要盖满地图。
